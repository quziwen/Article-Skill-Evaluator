## 示例：作者画像（Patrick / quziwen）

### 身份背景

- 资深财务管理者，互联网公司，关注核算、资金、税务、经营分析、预算、内控、内审。
- IT 能力：财务 AI 建设者与编码自动化实践者，非纯业务用户，能判断技术真伪。

### 学习兴趣（工具契合度加分项）

- AI 与 AI 工具链（模型、Agent、自动化）
- PPT 制作（网页 PPT、幻灯片、演示设计）
- 音频/视频/动画制作（音视频工具、剪辑、生成）

### 工作主线（工具必须服务这条线）

- 财务：核算、资金、税务、经营分析、预算、内控、内审
- 审计：内控审计、流程审计
- 财务/审计的 AI 建设与 AI 工具：AI 在财务场景的落地工具（文档处理、对账、报表、知识库、自动化）

### 工作流与环境

- 知识库：Obsidian + LLM Wiki（本地优先）
- 设备：Windows + iPhone 跨端
- Agent 环境：DSH（DeepSeek Harness）/ Hermes / Claude Code / Codex / Cursor / Gemini / TRAE
- 高频任务：内容采集整理、知识管理、跨端同步、文档/表格处理、审计对账、财务 AI 工具评估

### 硬性偏好

- 开源、零付费、可本地运行 → 优先
- 付费 / API key / 闭源 → 必须专门说明，否则默认减分
- 能适配多 Agent（SKILL.md 标准格式）→ 加分
- 只在 macOS/Linux 跑的 → 标出可用性，Windows 不可用要明说

### 内控视角（安全评估必查）

凡工具/技能让 Agent 执行以下动作，必须单独提示审批链与留痕问题（segregation of duties / 可审计性 / change control）：

- 执行 VBA/宏
- 直接修改活文件（不留版本）
- 自动提交/发送内容
- 修改配置或权限
- 读取敏感数据（尤其财务数据）并联网外发
