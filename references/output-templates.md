# 输出模板

## 裸链接或快速阅读

```markdown
**结论**
<一句话说明文章讲什么以及是否值得继续读>

**主要观点**
- <观点 1>
- <观点 2>
- <观点 3>

**初步判断**
- 证据：<强/中/弱，理由>
- 价值：<可直接采用/可作启发/需谨慎>
- 待确认：<没有则写“无关键待确认项”>
```

## 完整评判

```markdown
**结论**
<对文章质量、可信度和用户相关性的综合判断>

**文章主旨**
<忠实复述作者解决的问题和核心答案>

**关键观点与证据**
| 观点 | 原文证据 | 判断 |
|---|---|---|
| <观点> | <数据/案例/引文/无> | <支持充分/部分支持/未支持> |

**可借鉴内容**
- <可直接采用的内容及条件>

**主要问题**
- <证据缺口、逻辑跳跃、适用边界或时效问题>

**对当前工作的启示**
- <具体行动、验证或决策建议>

**待确认**
- <需要权威来源、内部数据或实测确认的内容>

**读取范围**（仅有影响判断的缺口时）
- <已取得哪些内容；长页停止原因、未读分页/图片文字；不要把 PASS 直接写成全文已读>
```

## 读取失败

仅在没有可用正文时使用下方模板。`status=BLOCKED` 但有 `partialResult` 时，先核对其中的真实正文，说明已读范围和后备路线为何受阻；足以回应的部分可按“完整评判”给有限判断，不能写成完全未取得正文。

```markdown
**结论**
当前未取得可验证正文，不能对文章内容作实质判断。

**已尝试**
- <路线 1 与结果>
- <路线 2 与结果；未尝试第二路线时说明原因>

**阻断原因**
<LOGIN_WALL / PAYWALL / CAPTCHA / PERMISSION_DENIED / ANTI_BOT /
TOOL_MISSING / NETWORK_ERROR / EMPTY_OR_SHELL_PAGE / UNSUPPORTED_FORMAT / HOST_BROWSER_POLICY>

**最小补救**
<一个具体动作，例如提供公开链接、导出 PDF 或粘贴正文>
```
