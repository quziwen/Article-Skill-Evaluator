# Quiz / 闪卡生成（增强能力 · 三选一产出）

> 来源：Content-Enhancer 合并。从文章内容提取关键知识点，生成自测题与记忆卡片。契合有学习检验需求的用户（把读到的内容变成可检验的知识）。
> **产出三选一，用户指定或按场景默认**：①对话内交互测验（默认）②单文件 HTML 测验页（可分享）③Anki 导入（记忆用）。Markdown 始终作为底稿保留。

## 流程

1. 从文章内容提取关键知识点（概念、数据、结论、方法）
2. 生成 3-5 道 Quiz 题（选择题 + 问答题混合）
3. 生成闪卡（正面=问题，背面=答案）
4. 先产出 Markdown 底稿（`Quiz-《标题》.md`）
5. 按用户选择（或场景默认）产出最终形态：交互测验 / HTML 页 / Anki 导入

## 使用方式

```
给这篇文章出Quiz [URL/文章内容]        → 默认对话内交互测验
生成闪卡 [URL/文章内容]                → 默认 Anki 导入格式
出Quiz，要HTML版 [URL]                → 单文件 HTML 测验页
出Quiz，要Anki [URL]                  → Anki 可导入 CSV
```

**形态选择规则**：
- 用户明确说"HTML / 网页版 / 发群里" → HTML 单文件
- 用户说"Anki / 背单词 / 记忆卡" → Anki 导入
- 用户说"做题 / 测验 / 自测" 或未指定 → 对话内交互测验（默认）
- 用户只要文档存档 → 仅 Markdown 底稿

---

## 形态①：对话内交互测验（默认）

在 Agent 对话中直接渲染可点选的测验，用户当场作答、当场判分、看解析。

**DSH / 支持交互组件的环境**：渲染交互式测验组件（每题单选 + 交卷判分 + 逐题解析）。

**不支持交互组件的环境（Claude Code / Codex 等纯文本）**：输出 Markdown 选择题 + 折叠答案，引导用户口答后展开对照：

```markdown
## Quiz - 《文章标题》

**1. [问题]？**
- A. [选项]
- B. [选项]
- C. [选项]
- D. [选项]

> 答案：<details><summary>点击查看</summary>正确答案：A。解析：……</details>
```

---

## 形态②：单文件 HTML 测验页（可分享）

生成一个**独立 HTML 文件**（内嵌 CSS+JS，无外部依赖），浏览器打开即可作答、自动判分、显示得分与解析。可发群里/飞书/微信，对方双击打开就能做。

- 文件名：`Quiz-《标题》.html`
- 结构：题目列表（单选）→ 交卷按钮 → 判分结果 + 每题解析
- 样式：简洁居中卡片，白底，移动端可用
- 含 3-5 道选择题（问答题以"参考答案"折叠区展示）
- 全部内联（无 CDN），离线可用

**生成方式**：在对话内直接产出完整 HTML 代码，写入文件后交付路径。

---

## 形态③：Anki 导入（记忆用）

生成 **Anki 可导入的 CSV**（UTF-8），列：`正面,背面`。Anki 桌面端「文件 → 导入」选择该 CSV，字段映射为 正面/背面 即可生成卡组。

- 文件名：`Flashcards-《标题》.csv`
- 闪卡 5-10 张，正面=问题，背面=答案
- 编码 UTF-8（带 BOM，避免 Anki 中文乱码）
- 可选附加字段：标签（`#article #读书笔记`）

```csv
正面,背面
词元（Token）是什么,AI 世界的最小计量单位
我国日均词元调用量（2026年8月）,约 140 万亿，较 2024 年初增长超千倍
```

---

## Markdown 底稿（始终保留）

无论选哪种形态，先产出 Markdown 底稿存档（可进 Obsidian / 笔记）：

```markdown
# Quiz - 《文章标题》

## 选择题

1. [问题]？
   A. [选项]
   B. [选项]
   C. [选项]
   D. [选项]
   ✅ 答案：[正确答案]

## 问答题

1. [问题]
   💡 答案：[核心答案]

## 闪卡

| 正面 | 背面 |
|------|------|
| [问题] | [答案] |
| [问题] | [答案] |
```

---

## 注意

- 题目必须忠于文章内容，不编造文章没有的知识点。
- 选择题 3-4 道 + 问答题 1-2 道为宜；闪卡 5-10 张。
- 财务/专业文章优先出"数据口径、关键结论、方法步骤"类题目，贴近实用检验。
- 可与深度模式联动：深度分析后出 Quiz 检验是否真正理解。
- HTML 版必须完全离线可用（无 CDN、无外链），保证发出去任何人打开都能做。
