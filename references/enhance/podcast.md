# 文章转播客（TTS 音频生成 · 增强能力）

> 来源：Content-Enhancer 合并。对已取得/已读取的文章生成播客风格音频。契合有音频/内容创作需求的用户。

## 流程

1. 获取文章内容（正常读取路线；付费或登录内容仅按 [授权读取](paywall-bypass.md) 使用用户有权访问的正文）
2. 结构化内容为播客脚本：开场引入 → 章节要点（每章 1-2 句核心）→ 总结收尾
3. 调用 `text_to_speech` 生成 MP3 音频（本机 TTS 能力或配置的 TTS 服务）
4. 输出到桌面或用户指定位置

## 使用方式

```
把这篇文章做成播客 [URL/文章内容]   → 读文 → 播客脚本 → TTS → MP3
生成音频摘要 [URL]                  → 只做摘要版音频
```

## 示例输出

```
已读取文章《xxx》
  → 播客脚本（开场 + 3 章节 + 总结）
  → TTS 生成 MP3
  → 输出：xxx_podcast.mp3（桌面）
```

## 注意

- 播客使用 TTS 技术生成，非真人录音；如后续要真人配音，保留脚本即可。
- 长文建议章节数 3-5，单集时长控制在可听范围（约 3-8 分钟）。
- 音频文件命名 `{文章标题}_podcast.mp3`，Windows 非法字符替换同归档规则。
