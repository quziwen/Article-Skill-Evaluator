# 付费墙绕过（增强能力 · 用户明确要求时启用）

> 从 Content-Enhancer 恢复的付费墙读取能力。**默认不启用**——只有用户明确要求"绕过付费墙读这篇/读这篇付费文章"时才执行。日常读取走正常路线，读到付费墙时报告，不自动尝试绕过。
>
> **内控边界（Patrick 财务+内审视角，必须遵守）**：验证码、账号登录墙、公司内网权限、文档权限**始终不绕过**（这些是人机验证/身份鉴权，绕过属于欺诈或越权）。付费墙绕过仅针对"已公开发布、但页面要求付费订阅才能看全文"的内容。

## 触发条件

用户明确要求读取付费墙内容（NYT、WSJ、Bloomberg、FT、Economist、WIRED、Forbes、Washington Post 等）时，按以下顺序尝试，成功即止。

## 6 层策略（按顺序，逐层标注性质）

| 层 | 方法 | 性质 |
|----|------|------|
| L1 | Jina Reader 代理：`https://r.jina.ai/<url>`（或 defuddle.md / markdown.new） | ✅ 公开代理读取，非伪造身份，首选 |
| L4 | archive.today 快照：`https://archive.today/newest/<url>` | ✅ 公开存档，非绕过授权 |
| L5 | Google Cache：`webcache.googleusercontent.com/search?q=cache:<url>` | ✅ 公开缓存（该服务已逐步停用） |
| L3 | AMP 版页面 / 清 cookie | ⚠️ 规避访问控制，次灰 |
| L6 | xcrawl 云端渲染 | ⚠️ 云端渲染兜底 |
| L2 | Googlebot UA + X-Forwarded-For 伪装 | 🔴 **身份伪装**，最灰，仅用户明确点名"用爬虫身份"时用 |

## 使用方式

```
绕过付费墙读这篇FT文章 [URL]     → 按 L1→L4→L5→L3→L6 顺序尝试（默认不用 L2）
抓取这篇WSJ文章 [URL]            → 优先公开代理/存档层
```

输出必须注明命中的层级与实际来源（"来源：archive.today 存档" / "来源：Jina 代理读取"），便于追溯。

## 合规与内控提示（必读）

- 付费墙绕过仅供**个人学习研究**，遵守相关法律法规与站点条款。
- **优先 L1/L4/L5（公开代理/存档）**；L3/L6（规避访问控制）仅用户要求时用；**L2（身份伪装）仅用户明确点名"用爬虫身份"时用**，且书面标注来源。
- 若读取内容将用于公司业务/对外材料/决策引用，**直接走合法渠道**（订阅/授权/企业订阅），不做任何绕过。
- **始终不绕过**：验证码（人机验证）、账号登录墙、公司内网权限、文档权限、地区限制——这些不是"付费墙"，绕过属于欺诈或越权，是硬红线。
- 公开摘要、预印本、新闻稿不能冒充付费原文；缺失内容标记"未取得"。

## 输出要求

- 写明实际读取的是"公开代理读取""公开存档快照"还是"身份伪装获取"（后者仅限用户点名场景）。
- 保留来源链接与访问日期。
